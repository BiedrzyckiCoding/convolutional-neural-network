Instructions
Implement, train, and test a neural network model for classifying images from the CIFAR-10 dataset. The dataset consists of 60,000 color images (32×32 pixels) divided into 10 classes, including cars, dogs, ships, and more.  

Model Guidelines:  
- Use Conv2D, Dropout, Dense, MaxPooling2D, and Flatten layers.  
- If your network exceeds 10 layers, use a kernel_initializer to improve performance and prevent the vanishing gradient problem.

Required Outputs:  
- Network architecture visualization  
- Exported model file (`.keras`)  
- Confusion matrix  
- Training history plot (accuracy/loss curves)  
- Final accuracy on the test data  
- Source code
